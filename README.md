# College Attendance Management System

This project is a Django-based web application used to manage college student attendance. 
It allows administrators to record, view, and manage attendance data efficiently.

The system helps reduce manual attendance tracking and provides an organized way to manage student records.

## Features
- Student attendance management
- Add and manage student records
- View attendance reports
- Database storage using SQLite
- Web interface built with Django

## Technologies Used
- Python
- Django
- HTML / CSS
- SQLite Database

## Installation
1. Clone the repository
git clone https://github.com/punyakshii/College-Attendance-Management-System.git

2. Install dependencies
pip install -r requirements.txt

3. Run the server
python manage.py runserver
